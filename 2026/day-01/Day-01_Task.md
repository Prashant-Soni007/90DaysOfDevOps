# 90-Day DevOps & Cloud Learning Plan

## My Understanding of DevOps & Cloud Engineering
DevOps is the practice of breaking down the wall between development and operations — using automation, monitoring, and collaboration to ship software faster and more reliably. Cloud Engineering is about designing, deploying, and managing infrastructure on platforms like AWS/Azure/GCP instead of physical servers, so systems can scale on demand and recover quickly from failure.

## Why I'm Starting DevOps & Cloud
I want to move beyond just writing code and take ownership of the entire deployment lifecycle. DevOps and Cloud skills will make me a stronger, more independent engineer and open doors to better roles and opportunities.

## 90-Day Goals
1. Deploy a production-grade application on Kubernetes with CI/CD automation end-to-end.
2. Get comfortable managing cloud infrastructure (AWS) using Infrastructure as Code (Terraform).
3. Build and showcase 3 real projects on GitHub that demonstrate DevOps skills to recruiters.

## Core Skills to Build
1. Linux administration & troubleshooting
2. CI/CD pipelines (Jenkins/GitHub Actions)
3. Kubernetes deployment & debugging

## Weekly Time Budget
- **Weekdays:** 2–2.5 hours/day (after work hours)
- **Weekends:** 4–6 hours/day

## How I'll Stay Consistent
I'll track daily progress in a public GitHub log and post short updates on LinkedIn to stay accountable. On low-energy days, I'll commit to at least 30 minutes rather than skipping entirely, to protect the streak.
